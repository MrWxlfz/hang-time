# Try the project

Start with the authorship note in the README. This is a demo to explore and change.

1. Open `index.html`. Try a section link, checkbox, and expandable note.
2. Find those elements in the HTML. Notice that the browser handles them without JavaScript.
3. Change a heading and refresh. Change a color in `style.css` and refresh again.
4. Make the browser narrow. Find the media query that changes the layout.
5. Fold both planes using the linked guides. Print the flight log, then record three throws for each plane.
6. Add your real results and a photo you took. Update the photo credit too.
7. Publish with GitHub Pages using the README instructions.

Before sharing, check both pages on a phone, follow every link, and use Tab to check keyboard navigation. Open print preview on the flight log and check that it fits on one page.
