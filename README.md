# Hang Time

Luke Nordin's **Boba Drop demo** about paper airplanes. Pick two designs, throw each three times, and compare how far they go.

Just HTML and CSS. No packages, JavaScript, or build step.

## What's here

- `index.html` — the planes, test instructions, and a few troubleshooting notes
- `flight-log.html` — a sheet to print and write your results on
- `style.css` — styles for both pages, including phones and printing
- `paper-plane.jpg` — the photo
- `WORKSHOP.md` — a short walkthrough
- `CREDITS.md` — photo and folding-guide sources

## Run it

Open `index.html` in a browser. Keep the files together. The checklist is temporary; the flight log is for printing, not saving data online.

## GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/(root)**. Save and open the site URL GitHub shows after deployment.

## A few things to try

Take your own plane photo, add your actual results, or test a third design. Change one thing between tests so you know what affected the flight.
